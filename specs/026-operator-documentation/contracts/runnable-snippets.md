# Contract: Runnable Snippets

**Feature**: 026 · **Requirements**: FR-008, FR-020, FR-026, FR-043 · **Research**: OD-12, OD-13

How operator pages mark the commands and files the pipeline executes.

## 1. Markers

An HTML comment on the line immediately before a fenced block:

```text
<!-- qb:run  procedure=<name> step=<n> [substitute=<name>[,<name>…]] -->
<!-- qb:file procedure=<name> step=<n> path=<relative path> [substitute=<name>[,<name>…]] -->
```

- `qb:run` blocks are `bash` or `sh` and are appended to the procedure's `run.sh` in step order.
- `qb:file` blocks are written verbatim to `path` (relative to the working directory) before
  `run.sh` starts.
- A block without a marker is never executed. Commands an operator should *not* run blindly
  (destructive restore steps) are still marked; the runner executes them in its sandbox.
- One block may belong to only one procedure; a page may hold several procedures.
- A procedure's steps may span pages; the `backup` and `restore` procedures are separate so a
  test can remove the original installation between them.

## 2. Substitutions (closed list)

A substitution replaces a whole block, or an exact placeholder within it, with something the
CI environment can run. Nothing else may differ from what an operator runs.

| Name | Applies to | Operator runs | Runner uses |
|---|---|---|---|
| `release-compose` | the download step | `curl -fsSLO https://…/releases/download/v{version}/docker-compose.yml` | copies the candidate's `assets/docker-compose.yml` (release) or the branch's file with `QUICKBUILDER_IMAGE` set (PR) |
| `image` | `{image}` placeholder | `ghcr.io/trungnd1985/quickbuilder:{version}` | the digest under test |
| `test-certificates` | certificate lines in proxy files | ACME / certbot paths | a throwaway CA and leaf certs generated by the test, mounted at the same paths; for Caddy a `local_certs`-free `tls <cert> <key>` line; for Traefik a file-provider default certificate replacing the resolver |
| `host-names` | `example.com`, `admin.example.com`, `shop.example.net` | the operator's own names | the same names, resolved to the proxy with `curl --resolve` |
| `ports` | published proxy ports such as `"443:443"` | the standard ports | free ports on `127.0.0.1`, so a test never collides with anything on the runner |
| `secret` | `change-me-before-real-use` placeholders | a value the operator generates | a random value generated by the runner |

`test-certificates`, `host-names` and `ports` take `from>to` pairs separated by `;`; every
`from` must occur in at least one block of the procedure marked with that substitution (a
proxy's certificate paths span its configuration file and its compose file), so an edited page cannot silently skip a substitution, and
`\n` in a `to` is a line break.

`snippets write` fails when a block marked `substitute=X` is not covered by a supplied `X`.

## 3. Procedures and their assertions

The assertions live in `tests/QuickBuilder.SmokeTests/Procedures/` (category `Procedures`),
never in the docs, so the docs contain only what an operator does.

| Procedure | Page | After `run.sh` the test asserts |
|---|---|---|
| `install` | `install.md` | `/health/ready` 200; setup with the code from the logs; the smoke journey (create, publish, view). |
| `backup`, then `restore` (the test runs `docker compose down -v` on the original between them, so both can use the same port) | `backup-restore.md` | Seeded content identical after restore into a fresh compose project; smoke journey passes; restoring the dump into an image one minor *older* is refused with the gate's message (edge case). |
| `nginx` / `caddy` / `traefik` | `reverse-proxy/<proxy>.md` | HTTPS on two site host names; admin answers only on `admin.example.com` when `Hosting:AdminHostNames` is set; sign-in works with `Identity:AllowInsecureHttp=false`; security event records the client address; a 5 MB upload is accepted (larger than every proxy's default body limit, within `Media:MaxFileSizeBytes`). |
| `proxy-basepath` | `reverse-proxy/index.md` (sub-path variant, run with Nginx) | Site at `/cms/…`; `/robots.txt` reaches the product. |

## 4. When they run

| Event | Procedures | Image |
|---|---|---|
| Pull request touching `docs/operators/**`, `docker-compose.yml`, `Dockerfile` or `src/QuickBuilder.Host/appsettings.json` | all | built from the branch |
| Release tag (`release.yml`) | all, as job `procedures` (matrix), in `candidate.needs` and the failure-banner list | the candidate digest |
| Other pull requests | none | — |
