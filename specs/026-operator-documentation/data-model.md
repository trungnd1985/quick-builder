# Data Model: Operator Documentation

**Feature**: 026 · **Spec**: [spec.md](spec.md) · **Research**: [research.md](research.md)

This feature stores nothing in the database. Its "data" is the setting catalog derived from
code, the files it generates, and the published site's layout.

## 1. Setting catalog (in memory, built by `qb-docs`)

Built by reflection over every loaded `QuickBuilder.*` assembly (OD-01, OD-02).

### SettingsSection

| Field | Source | Rule |
|---|---|---|
| `Key` | `[SettingsSection(key)]` | Unique across the catalog. Matches the class's `SectionName` const (checked). |
| `Area` | `[SettingsSection(Area=…)]` | One of the areas in §2; decides the page heading and note file. |
| `Title` | `[SettingsSection(Title=…)]` | Heading shown in the reference. |
| `Type` | the annotated class | Must have a public parameterless constructor. |
| `Settings` | public settable properties, recursively through `[SettingsGroup]` | Each property is `[Setting]`, `[SettingsGroup]` or `[NotASetting]`; anything else fails the check. |

### SettingDefinition

| Field | Source | Rule |
|---|---|---|
| `Key` | section key + property path, `:`-joined | Lists add `:<n>`, dictionaries `:<name>` (OD-05). Unique. |
| `EnvironmentName` | `Key` with `:` → `__` | Lists shown as `…__0`, `…__1`. |
| `Type` | CLR type → `text`, `true/false`, `whole number`, `decimal`, `duration (hh:mm:ss)`, `URL`, `one of: …` (enum names), `list of …`, `map of …` | Unknown CLR types fail the check. |
| `Default` | binding shipped `appsettings.json` onto a new instance (OD-02), or `DefaultText` | Rendered `*(none)*` when null/empty and `Required`; `*(empty)*` when empty and optional. |
| `DefaultIsComputed` | `DefaultText` present | Listed by `settings check` for review. |
| `Required` | `[Required]` | — |
| `Allowed` | `[Range]`, `[AllowedValues]`, `[Length]`/`[MinLength]`/`[MaxLength]`, enum names, `[Setting(Format=…)]` | `[RegularExpression]` requires `Format` (a human description); the regex itself is not shown. |
| `Description` | `[Setting(description)]` | Non-empty, ≥ 1 sentence, ends with `.`, no requirement IDs (`FR-`, `SC-`, `OD-` …). |
| `Secret` | `[Setting(Secret=true)]` | Rendered with the secret notice (US2 scenario 3). |
| `AppliesWhen` | `[Setting(AppliesWhen=…)]` or inherited from `[SettingsGroup]` | Must name a declared setting and a value, e.g. `Storage:Provider = S3`. |
| `Deprecated` | `[DeprecatedSetting(replacement, removeIn)]` | `replacement` must be a declared key or empty; `removeIn` a version > current. |
| `ObservedLazily` | `[Setting(ObservedLazily="reason")]` | Exempt from "declared ⇒ observed"; listed by the check. |

### ExternalSetting

Settings read by third-party code (Serilog) are described by a class in
`src/QuickBuilder.Host/Configuration/ExternalSettings.cs` that carries the same attributes as
an options class but is never bound by the product. The catalog therefore treats them exactly
like product settings, with defaults from `appsettings.json`; no separate list or type exists.

### Exclusion

| Field | Rule |
|---|---|
| `Pattern` | Exact key or `Prefix:*` (or `PREFIX_*`) |
| `Reason` | Non-empty |
| `Kind` | `framework` (allow-list in `qb-docs`), `not-a-setting` (`[NotASetting]` on a member) or `computed` (a public property configuration cannot set) |

Every exclusion is printed by `settings check` (FR-016).

## 2. Areas (fixed order on the page)

`required`, `database`, `hosting`, `admin`, `identity`, `storage`, `media`, `transfer`,
`outbox`, `trash`, `preview`, `menus`, `editing`, `email`, `forms`, `cache`, `telemetry`,
`logging` — today's `docs/configuration.md` order. A new area requires adding it here and in
the tool's enum (a deliberate, reviewed change).

## 3. Generated files

| File | Generator | Checked by |
|---|---|---|
| `docs/operators/reference/configuration.md` | `qb-docs settings generate` | Unit test `SettingsReferenceIsCurrent` (byte-identical after `\n` normalisation) |
| `docs/operators/upgrade-notes.md` | `qb-docs upgrade-notes generate` | Release `prepare` regenerates and fails if it differs from the tag (the fragment must have been archived first) |

Both start with `<!-- Generated by qb-docs … Do not edit; see docs/contributing.md#operator-docs -->`.

### Reference table shape (stable; parsed by 019's `ConfigurationKeys`)

```markdown
| Key | Environment variable | Type | Default | Allowed values | Description |
|---|---|---|---|---|---|
| `Database:AutoMigrate` | `Database__AutoMigrate` | true/false | `true` | — | Apply migrations during startup. … |
```

Allowed values: `—` when unconstrained; ranges as `16 – 16384`; enums and `[AllowedValues]`
as `` `Local`, `S3`, `AzureBlob` ``; a `Format` text verbatim. Required settings carry **Required.** at the start of the description; secrets carry
**Secret.** and the standard sentence; `AppliesWhen` renders as a sub-heading per group
("S3-compatible (`Storage:Provider` = `S3`)"); deprecated settings render
**Deprecated — use `X`; removed in 2.0.**.

## 4. Published site layout (`gh-pages` branch)

```text
/index.html              redirect to /<latest stable minor>/
/versions.json           [{ "line": "0.3", "release": "0.3.2", "published": "2027-01-10" }, …] newest first
/0.2/…                   VitePress output, base /<repo>/0.2/
/0.3/…
/.nojekyll
```

### State transitions of a minor line

```text
(absent) --release X.Y.0 promoted--> published(X.Y.0)
published(X.Y.n) --release X.Y.m (m>n) promoted--> published(X.Y.m)   (folder replaced)
published(X.Y.n) --anything else--> unchanged                          (FR-039)
```

The root redirect points at the highest published stable line; it changes only when a
promoted release is `highest` (OD-08). Pre-releases never create or change a line.

## 6. Runnable snippet

| Field | Source | Rule |
|---|---|---|
| `Procedure` | `procedure=` in the marker | One of `install`, `backup`, `restore`, `nginx`, `caddy`, `traefik`, `proxy-basepath`. |
| `Kind` | `qb:run` or `qb:file` | `file` requires `path=` (relative, no `..`). |
| `Step` | `step=` | Integer, unique per procedure; steps run in order. |
| `Substitutes` | `substitute=`, comma-separated | Each one of the names in [contracts/runnable-snippets.md](contracts/runnable-snippets.md). |
| `Body` | the fenced block immediately after the marker | Must be `bash`/`sh` for `run`; any language for `file`. |

`qb-docs lint` fails on a marker not followed by a fenced block, duplicate steps, an unknown
procedure or substitution, and a procedure with no `run` step.
